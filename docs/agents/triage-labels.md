# Triage labels

Канонические роли навыков соответствуют следующим меткам GitHub Issues:

| Роль | Метка | Значение |
| --- | --- | --- |
| needs-triage | needs-triage | Требуется первичная оценка задачи |
| needs-info | needs-info | Требуется дополнительная информация от автора |
| ready-for-agent | ready-for-agent | Задача полностью описана и готова для автономного агента |
| ready-for-human | ready-for-human | Требуется реализация человеком |
| wontfix | wontfix | Задача не будет выполняться |

Когда навык указывает роль, применяй соответствующую метку из таблицы.
При изменении словаря обновляй столбец «Метка».
