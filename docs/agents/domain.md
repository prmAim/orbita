# Доменная документация

## Структура

Проект использует single-context:

- `GLOSSARY.md` в корне — термины предметной области.
- `docs/adr/` — архитектурные решения проекта.

## Перед исследованием проекта

Прочитай `GLOSSARY.md` и ADR, относящиеся к затрагиваемой области.

Если этих документов ещё нет, продолжай работу без отдельного
предупреждения и предложения создать пустые файлы. Навык
`domain-modeling` создаёт их по мере согласования терминов и решений.

## Терминология

В задачах, спецификациях, коде и тестах используй термины из глоссария.
Соблюдай зафиксированные различия между понятиями и ограничения
на использование синонимов.

Если нужного понятия нет, проверь, действительно ли оно относится
к предметной области. Выявленный пробел передай в `domain-modeling`.

## Архитектурные решения

При противоречии с существующим ADR явно укажи документ,
суть противоречия и причину предлагаемого пересмотра.
Изменение решения оформляй явно.
