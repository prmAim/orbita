# Серверная сессия локальной панели

15 ноября 2026 года владелец уточнил R36: локальная панель использует серверную сессию без тайм-аута бездействия, явный выход и отзыв старого доступа при сбросе пароля. Закрытие браузера не является гарантированным выходом: после восстановления вкладок вход может сохраняться. Это осознанно заменяет прежнее требование повторного входа после каждого полного закрытия браузера и соответствующую проверку A194.

Решение сохраняет обычную веб-архитектуру без отдельного компонента Windows для наблюдения за браузером и без принудительного выхода при обновлении страницы. Доступ к журналу и управлению после явного выхода или сброса пароля остаётся запрещён до нового входа; состояние повторения, журнал и настройки от завершения сессии не меняются.

Основания: [R36](https://github.com/prmAim/orbita/issues/10), [A194–A197](https://github.com/prmAim/orbita/issues/8). Ограничение восстановления сессионных cookie описано в [MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Set-Cookie); управление завершением сессии — в [OWASP](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html). Отсутствие тайм-аута бездействия — явно выбранное требование владельца для локальной панели.
