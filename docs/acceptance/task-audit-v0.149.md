**ПОКРЫТО ЛОКАЛЬНО** — все составляющие критерия подтверждены совокупностью конкретных тестов, кода и сохранённых результатов; это не разрешение на реальную торговлю. **ЧАСТИЧНО** — указан конкретный недоказанный пункт. **ДЕФЕКТ** — есть подтверждённое расхождение реализации, помимо возможных пробелов проверки. **ОТЛОЖЕНО LIVE/OPS** — реальный счёт или эксплуатационный этап, который владелец перенёс на конец. Не требуется объединять независимые составляющие критерия в один тест; совместное испытание нужно только там, где сам критерий требует их взаимодействия.

Свежие запуски этим рецензентом: **NOT_RUN**. Основной агент подтвердил на том же `2392b8c` успешные удалённые [Java/TypeScript CI](https://github.com/prmAim/orbita/actions/runs/43908948559) и [Python CI](https://github.com/prmAim/orbita/actions/runs/43908948448): 249 Java и 24 Python теста.
