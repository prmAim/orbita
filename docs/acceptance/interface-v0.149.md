## Что выявила фактическая интеграция

- PostgreSQL округляет timestamp до микросекунд. Подтверждённое исполнение
  SDK с наносекундами ошибочно конфликтовало с сохранённой копией. Исправлена
  только эта граница сравнения; raw/raw остаётся строгим. Регрессии включают
  перенос секунды, manual provenance и действительные различия цены/времени.
- Первый браузерный runner терял причину ошибки и действовал до кадра
  восстановления навигации. Диагностика и ожидание двух кадров исправлены;
  строгие проверки Back не ослаблены. Два последовательных Large прогона и
  Standard прошли на реальном стенде. Код приложения ради этого не менялся.
- Реальный Remove безопасно отказал из-за текстового представления одного
  времени в JDBC `+05:00` и psql UTC. Снимки теперь сравниваются через типы
  таблицы, без переписывания реестра и без исключения полей. Реальная смена
  момента времени и raw-наблюдений по-прежнему запрещает очистку. После
  регрессий и ревью тот же сохранённый Large удалён штатной командой.
