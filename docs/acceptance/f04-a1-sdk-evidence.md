Основание: [спецификация, §§2–3.3 и A01/A02/A05](../specifications/f04-r52-rejection-classification.md).

## Изменённая граница

`OrderEvidence.sdkEvidence` сохраняет исходные unary-ответы и четыре безопасных
поля ошибки SDK 1.51 отдельно от квалифицированного результата. Старые
конструкторы совместимы. Проверки ответа не теряют его сырые идентификаторы,
числовой status и исполненный объём при UNKNOWN. Переданный PostOrder UUID
проверяется; отсутствующий UUID не выдумывается из запроса. CANCELLED и REJECTED
без квалифицированной причины получают OTHER; NEW остаётся активным.
Полный контракт и граница A2 описаны в [архитектуре](../architecture/application.md).

сертификаты, токен и счета синтетические. Производственные API, счета и Telegram
не вызывались. Предупреждение JDK о native access Netty не является ошибкой теста.

```powershell

  "-Dmaven.repo.local=$repository" `

  '-Dtest=OrderSdkEvidenceTest,OrderSdkTlsTest,TInvestBrokerGatewayTest' `

```

`spotless:check`. Каталог сборки отдельный: `.scratch/f04-a1-build`.

журналах. Эти команды не запускают приложение и не требуют производственной БД.
