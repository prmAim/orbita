# Инструкции для агентов

## Agent skills

### Issue tracker

Задачи и спецификации хранятся в GitHub Issues репозитория
`prmAim/orbita`. Перед работой с задачами прочитай
[правила трекера](docs/agents/issue-tracker.md).

### Triage labels

Используются пять стандартных меток triage. Перед классификацией
задач прочитай [соответствие меток](docs/agents/triage-labels.md).

### Domain docs

Структура single-context: корневой `GLOSSARY.md` и `docs/adr/`.
Перед исследованием проекта прочитай
[правила доменной документации](docs/agents/domain.md).
