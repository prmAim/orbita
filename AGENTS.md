## Context7

Перед выбором библиотек и написанием кода, зависящего от библиотек,
фреймворков, SDK или платформ, сначала получи через Context7 актуальную
документацию и рекомендуемые подходы для используемой или рассматриваемой
версии. Учитывай ограничения проекта, совместимость и устаревшие API.
Используй `resolve-library-id`, затем `query-docs`; при известном точном ID
библиотеки можно сразу вызвать `query-docs`.

Если инструменты не видны сразу, проверь доступные отложенные инструменты
по имени `context7` перед выводом об отсутствии подключения. При реальной
недоступности Context7 или пробеле в документации используй официальные
источники и обозначь ограничение. Рейтинг Context7 сам по себе не определяет
пригодность библиотеки для проекта.

Настройка MCP для проекта находится в `.codex/config.toml`; ключ берётся
из переменной окружения `KeyToMcpContext7` и хранится вне репозитория.
